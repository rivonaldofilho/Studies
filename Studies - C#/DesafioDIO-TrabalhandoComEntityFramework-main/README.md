
# Projeto API - Trilha .NET

## 📋 Objetivo

Este projeto foi desenvolvido com o propósito de **aprender e praticar** conhecimentos fundamentais em:
- **Programação Orientada a Objetos (POO)**
- **Desenvolvimento de APIs REST**
- **Manipulação de Banco de Dados**

## 🛠️ Tecnologias Utilizadas

- **.NET** - Framework principal
- **C#** - Linguagem de programação
- **ASP.NET Core** - Desenvolvimento de APIs
- **Entity Framework Core** - ORM para acesso a dados
- **SQL Server** - Banco de dados relacional

## 📚 Conceitos Praticados

- Classes e herança
- Encapsulamento e polimorfismo
- CRUD (Create, Read, Update, Delete)
- Endpoints RESTful
- Consultas ao banco de dados
- Validação de dados

## 🚀 Como Usar

1. Clone o repositório
2. Configure a string de conexão do banco de dados
3. Execute as migrations
4. Inicie a aplicação
