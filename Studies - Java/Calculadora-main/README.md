# Calculadora Java — Projeto de aprendizado

Olá! Me chamo Rivonaldo e este é meu primeiro projeto em java. Comecei ele para colocar em prática meu aprendizado com ferramentas como "switch case", "do while" e "if else". Você pode ver também que pensei bem possíveis entradas do usuário para evitar error, validando entradas inválidas para permitir que o código continue.

## Como usar
- Compile (Windows):
    javac -d bin src\Calculadora.java
- Execute:
    java -cp bin Calculadora
- Siga as instruções na tela: digite dois números, escolha a operação (+ - * /) e opte por continuar (s/n).

## Observações rápidas
- O programa valida entradas inválidas e avisa quando necessário.
- Objetivo: praticar lógica e leitura de dados com Scanner.
