# Desafio Controle de Fluxo

Este projeto foi desenvolvido como parte de um desafio educacional proporcionado pela [DIO](https://www.dio.me/). O objetivo principal é praticar conceitos de criação e tratamento de exceções em Java, fundamentais para o desenvolvimento de aplicações robustas e seguras.

## Objetivo do Projeto

- Demonstrar o uso de estruturas de controle de fluxo em Java.
- Implementar e tratar exceções personalizadas, como a `ParametrosInvalidosException`.
- Consolidar boas práticas de programação orientada a objetos.

## Estrutura do Projeto

O projeto contém os seguintes arquivos principais:

- `Contador.java`: Classe principal que contém a lógica do programa.
- `ParametrosInvalidosException.java`: Classe que define uma exceção personalizada para validação de parâmetros.

## Como Executar

1. Certifique-se de ter o [Java JDK](https://www.oracle.com/java/technologies/javase-downloads.html) instalado em sua máquina.
2. Compile os arquivos Java localizados na pasta `src`.
3. Execute a classe principal `Contador`.

```bash
javac -d bin src/*.java
java -cp bin Contador
```
