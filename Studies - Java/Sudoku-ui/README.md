# Sudoku - Projeto Java

## Introdução ao Projeto
Este projeto é uma implementação do jogo Sudoku utilizando a linguagem Java. Através dele, foi possível aprimorar habilidades de programação orientada a objetos, design de interfaces gráficas e organização de código em projetos maiores. A estrutura do projeto foi cuidadosamente planejada para garantir modularidade e reutilização de código.

## Objetivo
O principal objetivo deste projeto foi criar uma aplicação funcional e interativa do jogo Sudoku. Durante o desenvolvimento, foram trabalhadas as seguintes habilidades:

- **Programação Orientada a Objetos (POO):** Criação de classes e interfaces para modelar o jogo e seus componentes.
- **Design de Interfaces Gráficas (GUI):** Desenvolvimento de uma interface amigável utilizando Java Swing.
- **Estruturação de Projetos:** Organização do código em pacotes e classes para facilitar a manutenção e evolução do projeto.
- **Manipulação de Eventos:** Implementação de listeners para capturar e tratar eventos na interface gráfica.
- **Enumerações:** Uso de enums para representar estados e eventos do jogo.

## Conclusão
Após finalizar o projeto, consegui evoluir meus conhecimentos em Java e explorar o desenvolvimento de aplicações desktop. Além disso, ele serve como um marco na evolução das habilidades de programação, destacando a importância de boas práticas de desenvolvimento e organização de código.
